# TransactCore Website — V2

Responsive corporate landing page using an original TransactCore design and copy. The page takes inspiration from the high-level structure of the supplied Paykassma reference (hero, solutions, markets, integration, industries, enquiry and FAQ) without copying its wording, imagery or brand assets.

## Files
- `index.html` — website content
- `style.css` — responsive styling
- `script.js` — mobile navigation and demo form behavior

## Preview
Open `index.html` in a browser.

## GitHub Pages publishing
1. Upload `index.html`, `style.css`, `script.js` and `README.md` to the root of the intended repository.
2. Open repository **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish and open the URL shown there.

## Before public launch
- Replace the CSS-built temporary brand mark with the approved TransactCore logo file, if available.
- The enquiry form is demo-only; it does not send or store submissions. Connect it to a verified business contact channel before publishing.
- Verify company details, contact information, legal notices, privacy policy and all service claims before launch.
- Do not claim licenses, provider authorizations, transaction volumes, uptime, settlement times or success rates unless verified and approved.
- Confirm the GitHub account and repository name used for the final website address.
